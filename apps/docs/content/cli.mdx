`@bolkauth/cli` automates common setup tasks in an existing project.

## Run Without Installing

<DlxTabs packageName="@bolkauth/cli" args={"<command>"} />

Or install globally:

<InstallTabs packages="@bolkauth/cli" global />

```bash
bolkauth <command>
```

## `bolkauth init`

Starts the interactive setup wizard:

<DlxTabs packageName="@bolkauth/cli" args="init" />

The wizard can create:

| File | Purpose |
|---|---|
| `lib/auth.ts` | `createBolkAuth` configuration. |
| `app/api/auth/[...bolkauth]/route.ts` | Next.js route handler. |
| `middleware.ts` | Route protection. |
| `.env.example` | Required environment variable names. |

## `bolkauth add`

Scaffold adapter-specific setup:

<DlxTabs packageName="@bolkauth/cli" args="add drizzle" />

<DlxTabs packageName="@bolkauth/cli" args="add prisma" />

Use the generated files as a starting point and adjust them to your project's database layout.

## `bolkauth generate`

Generate supporting files:

## Commands

| Command | Description |
|---|---|
| `bolkauth init` | Interactive project setup. |
| `bolkauth add drizzle` | Add Drizzle adapter files. |
| `bolkauth add prisma` | Add Prisma adapter files. |
| `bolkauth generate env` | Create an `.env.example`. |
| `bolkauth generate types` | Create TypeScript declaration scaffolding. |
| `bolkauth --help` | Print CLI help. |
| `bolkauth --version` | Print the installed version. |

## After Running the CLI

1. Install any new dependencies.
2. Fill in `.env.local`.
3. Run database migrations.
4. Start the Next.js app and test sign-up, sign-in, sign-out, and middleware redirects.
