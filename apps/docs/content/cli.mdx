The `@bolkauth/cli` tool automates BolkAuth project setup, database schema generation, and environment variable scaffolding. You can run it without installing globally using `npx`.

---

## 📦 Installation

```bash
# Run without installing (recommended)
npx @bolkauth/cli <command>

# Or install globally
pnpm add -g @bolkauth/cli
bolkauth <command>
```

---

## 🚀 `bolkauth init`

Interactive setup wizard that scaffolds a complete BolkAuth configuration in your existing Next.js project.

```bash
npx @bolkauth/cli init
```

**What the interactive wizard does:**

```
? Which ORM are you using?
  ❯ Drizzle ORM
    Prisma ORM
    None (I'll write a custom adapter)

? Which OAuth providers do you need?
  ◉ GitHub
  ◉ Google
  ◯ Discord
  ◯ Twitter

? Where do you mount the API handler? (app/api/auth/[...bolkauth]/route.ts)

? Does your app use onboarding? (Y/n)

✔  Created lib/auth.ts
✔  Created app/api/auth/[...bolkauth]/route.ts
✔  Created middleware.ts
✔  Created .env.example
✔  Updated package.json (added @bolkauth/core, @bolkauth/nextjs, @bolkauth/react)

🎉  BolkAuth initialized! Run `pnpm install` to install dependencies.
```

### Generated `lib/auth.ts`

```ts
// lib/auth.ts  — generated by `bolkauth init`
import { createBolkAuth } from "@bolkauth/core";
import { createDrizzleAdapter } from "@bolkauth/adapter-drizzle";
import { db } from "./db";

export const auth = createBolkAuth({
  adapter: createDrizzleAdapter(db),
  secret: process.env.BOLKAUTH_SECRET!,
  emailAndPassword: {
    enabled: true,
    minPasswordLength: 8,
  },
  socialProviders: {
    github: {
      clientId: process.env.GITHUB_CLIENT_ID!,
      clientSecret: process.env.GITHUB_CLIENT_SECRET!,
    },
    google: {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    },
  },
  onboarding: {
    enabled: true,
    requiredForAccess: true,
    redirectUrl: "/onboarding",
  },
});
```

### Generated `middleware.ts`

```ts
// middleware.ts  — generated by `bolkauth init`
import { bolkAuthMiddleware } from "@bolkauth/nextjs";
import { auth } from "@/lib/auth";

export default bolkAuthMiddleware(auth, {
  signInUrl: "/sign-in",
  onboardingUrl: "/onboarding",
  publicRoutes: ["/", "/sign-in", "/sign-up", "/api/auth"],
});

export const config = {
  matcher: ["/((?!.*\\..*|_next).*)", "/", "/(api|trpc)(.*)"],
};
```

## 🗄️ `bolkauth add [adapter]`

Scaffold database schema files for your chosen ORM.

### Drizzle

```bash
npx @bolkauth/cli add drizzle
```

**Output:**

```
✔  Created db/schema.ts
✔  Created drizzle.config.ts
✔  Created db/index.ts
✔  Installed drizzle-orm, drizzle-kit, pg, @types/pg
```

Generated `db/schema.ts`:

```ts
// db/schema.ts  — generated by `bolkauth add drizzle`
export {
  authUsers,
  authAccounts,
  authSessions,
  authVerificationTokens,
  authUserMetadata,
} from "@bolkauth/adapter-drizzle";
```

Generated `drizzle.config.ts`:

```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  schema: "./db/schema.ts",
  out: "./db/migrations",
  dialect: "postgresql",
  dbCredentials: {
    url: process.env.DATABASE_URL!,
  },
});
```

### Prisma

```bash
npx @bolkauth/cli add prisma
```

**Output:**

```
✔  Appended BolkAuth models to prisma/schema.prisma
✔  Installed @bolkauth/adapter-prisma, @prisma/client
✔  Installed prisma (dev)

Next steps:
  npx prisma migrate dev --name add_bolkauth
  npx prisma generate
```

## 🔧 `bolkauth generate [target]`

Generate configuration files and TypeScript declarations.

### `generate env`

Scaffold an `.env.example` file with all required environment variable names:

```bash
npx @bolkauth/cli generate env
```

**Generated `.env.example`:**

```bash
# ─────────────────────────────────────────────────────────────────
# BolkAuth — Required
# ─────────────────────────────────────────────────────────────────

# Minimum 32-character secret key for HMAC-SHA256 JWT signing.
# Generate: openssl rand -base64 32
BOLKAUTH_SECRET=

# ─────────────────────────────────────────────────────────────────
# Database
# ─────────────────────────────────────────────────────────────────

# PostgreSQL connection string.
# Example: postgresql://user:password@localhost:5432/myapp
DATABASE_URL=

# ─────────────────────────────────────────────────────────────────
# OAuth Providers (only required if using social login)
# ─────────────────────────────────────────────────────────────────

# GitHub OAuth App: https://github.com/settings/developers
GITHUB_CLIENT_ID=
GITHUB_CLIENT_SECRET=

# Google OAuth: https://console.cloud.google.com/apis/credentials
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

# ─────────────────────────────────────────────────────────────────
# App
# ─────────────────────────────────────────────────────────────────

# Public URL of your app (used in OAuth callback URLs for production)
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### `generate types`

Generate a TypeScript declaration file for augmenting BolkAuth types with your custom metadata:

```bash
npx @bolkauth/cli generate types
```

**Generated `types/bolkauth.d.ts`:**

```ts
// types/bolkauth.d.ts  — generated by `bolkauth generate types`
// Augment BolkAuth's user metadata with your app-specific shape.

import "@bolkauth/core";

declare module "@bolkauth/core" {
  interface BolkAuthUserMetadata {
    // Add your custom onboarding fields here:
    role?: "developer" | "designer" | "product" | "founder";
    teamSize?: "1" | "2-5" | "6-20" | "20+";
    industry?: string;

    // Add any other custom user metadata:
    plan?: "free" | "pro" | "enterprise";
    referralCode?: string;
  }
}
```

After editing this file, your hooks and server helpers will be fully typed:

```ts
const user = await getUser();
// user.metadata.onboardingData.role — typed as:
// "developer" | "designer" | "product" | "founder" | undefined
```

## 📋 All Commands Reference

| Command | Description |
|---|---|
| `bolkauth init` | Interactive full-project setup wizard |
| `bolkauth add drizzle` | Scaffold Drizzle schema, config, and DB client |
| `bolkauth add prisma` | Append Prisma models to existing schema |
| `bolkauth generate env` | Generate `.env.example` with all required keys |
| `bolkauth generate types` | Generate TypeScript declaration augmentation file |
| `bolkauth --version` | Print CLI version |
| `bolkauth --help` | Show help for any command |

### Global Flags

| Flag | Description |
|---|---|
| `--yes`, `-y` | Skip confirmation prompts (non-interactive mode) |
| `--cwd <path>` | Run as if in a different working directory |
| `--verbose` | Print detailed logs for debugging |

## 🤖 CI/CD Integration

### GitHub Actions

Use `bolkauth generate types` in your CI pipeline to ensure types are always up-to-date:

```yaml
# .github/workflows/type-check.yml
name: Type Check

on:
  push:
    branches: [main]
  pull_request:

jobs:
  typecheck:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install pnpm
        uses: pnpm/action-setup@v3
        with:
          version: 8

      - name: Install dependencies
        run: pnpm install

      - name: Generate BolkAuth types
        run: npx @bolkauth/cli generate types

      - name: Type check
        run: pnpm tsc --noEmit
```

### Running Migrations in CI

```yaml
      - name: Apply DB migrations (Drizzle)
        run: pnpm drizzle-kit migrate
        env:
          DATABASE_URL: ${{ secrets.DATABASE_URL }}
```

```yaml
      - name: Apply DB migrations (Prisma)
        run: npx prisma migrate deploy
        env:
          DATABASE_URL: ${{ secrets.DATABASE_URL }}
```
