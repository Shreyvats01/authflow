# CLI Reference

The `@bolkauth/cli` tool automates project initialization, database schema generation, and environment setup.

---

## 🚀 Commands

### `bolkauth init`

Interactive setup wizard to initialize BolkAuth in an existing project.

```bash
npx @bolkauth/cli init
```

### `bolkauth add [adapter]`

Scaffold database schema files for your chosen ORM:

```bash
# Generate Drizzle table definitions at db/schema.ts
npx @bolkauth/cli add drizzle

# Append Prisma BolkAuth models to prisma/schema.prisma
npx @bolkauth/cli add prisma
```

### `bolkauth generate [target]`

Generate environment templates or TypeScript declarations:

```bash
# Scaffolds .env.example with required environment variables
npx @bolkauth/cli generate env

# Generates custom TypeScript declarations at types/bolkauth.d.ts
npx @bolkauth/cli generate types
```
