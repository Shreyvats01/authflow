# Welcome to AuthFlow

**AuthFlow** is a modern, developer-first authentication library for TypeScript applications. It gives you Clerk-like developer experience, headless React hooks, and Next.js App Router integrations while letting you own your database and infrastructure completely.

---

## ⚡ Quickstart in 5 Steps

### 1. Install Dependencies

Install the core package, framework binding, and your database adapter:

```bash
pnpm add @authflow/core @authflow/nextjs @authflow/react @authflow/adapter-drizzle
```

### 2. Configure Auth Engine

Create `lib/auth.ts` to instantiate your AuthFlow engine:

```ts
import { createAuthFlow } from "@authflow/core";
import { createDrizzleAdapter } from "@authflow/adapter-drizzle";
import { db } from "./db";

export const auth = createAuthFlow({
  adapter: createDrizzleAdapter(db),
  secret: process.env.AUTHFLOW_SECRET!,
  emailAndPassword: {
    enabled: true,
    minPasswordLength: 8,
  },
  socialProviders: {
    github: {
      clientId: process.env.GITHUB_CLIENT_ID!,
      clientSecret: process.env.GITHUB_CLIENT_SECRET!,
    },
    google: {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    },
  },
  onboarding: {
    enabled: true,
    requiredForAccess: true,
    redirectUrl: "/onboarding",
  },
});
```

### 3. Expose API Route Handler

Create `app/api/auth/[...authflow]/route.ts`:

```ts
import { authFlowHandler } from "@authflow/nextjs";
import { auth } from "@/lib/auth";

const handlers = authFlowHandler(auth);

export const GET = handlers.GET;
export const POST = handlers.POST;
```

### 4. Wrap App with React Provider

Wrap your `app/layout.tsx` with `<AuthFlowProvider>`:

```tsx
import { AuthFlowProvider } from "@authflow/react";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <AuthFlowProvider config={{ baseURL: "/api/auth" }}>
          {children}
        </AuthFlowProvider>
      </body>
    </html>
  );
}
```

### 5. Protect Routes via Middleware

Add `middleware.ts` to secure protected paths:

```ts
import { authFlowMiddleware } from "@authflow/nextjs";
import { auth } from "@/lib/auth";

export default authFlowMiddleware(auth, {
  signInUrl: "/sign-in",
  onboardingUrl: "/onboarding",
  publicRoutes: ["/", "/sign-in", "/sign-up", "/api/auth"],
});

export const config = {
  matcher: ["/((?!.*\\..*|_next).*)", "/", "/(api|trpc)(.*)"],
};
```

## 🏛️ Monorepo Architecture

AuthFlow is built as a clean modular monorepo:

| Package | npm Package | Description |
|---|---|---|
| Core Engine | `@authflow/core` | Zero-dependency Web Crypto engine handling JWTs, hashing, OAuth, & state machines |
| React Bindings | `@authflow/react` | Headless hooks (`useSignIn`, `useSignUp`, `useUser`, `useOAuth`) & cross-tab sync |
| Next.js Helpers | `@authflow/nextjs` | Edge middleware, Next.js 14+ Route Handlers, & Server Component helpers |
| Drizzle Adapter | `@authflow/adapter-drizzle` | PostgreSQL table definitions and adapter logic for Drizzle ORM |
| Prisma Adapter | `@authflow/adapter-prisma` | Schema definitions and type-safe adapter for Prisma ORM |
| CLI Tool | `@authflow/cli` | Scaffolding wizard (`authflow init`, `add`, `generate`) |
