# Welcome to BolkAuth

**BolkAuth** is a modern, developer-first authentication library for TypeScript applications. It gives you Clerk-like developer experience, headless React hooks, and Next.js App Router integrations while letting you own your database and infrastructure completely.

---

## ⚡ Quickstart in 5 Steps

### 1. Install Dependencies

Install the core package, framework binding, and your database adapter:

```bash
pnpm add @bolkauth/core @bolkauth/nextjs @bolkauth/react @bolkauth/adapter-drizzle
```

### 2. Configure Auth Engine

Create `lib/auth.ts` to instantiate your BolkAuth engine:

```ts
import { createBolkAuth } from "@bolkauth/core";
import { createDrizzleAdapter } from "@bolkauth/adapter-drizzle";
import { db } from "./db";

export const auth = createBolkAuth({
  adapter: createDrizzleAdapter(db),
  secret: process.env.BOLKAUTH_SECRET!,
  emailAndPassword: {
    enabled: true,
    minPasswordLength: 8,
  },
  socialProviders: {
    github: {
      clientId: process.env.GITHUB_CLIENT_ID!,
      clientSecret: process.env.GITHUB_CLIENT_SECRET!,
    },
    google: {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    },
  },
  onboarding: {
    enabled: true,
    requiredForAccess: true,
    redirectUrl: "/onboarding",
  },
});
```

### 3. Expose API Route Handler

Create `app/api/auth/[...bolkauth]/route.ts`:

```ts
import { bolkAuthHandler } from "@bolkauth/nextjs";
import { auth } from "@/lib/auth";

const handlers = bolkAuthHandler(auth);

export const GET = handlers.GET;
export const POST = handlers.POST;
```

### 4. Wrap App with React Provider

Wrap your `app/layout.tsx` with `<BolkAuthProvider>`:

```tsx
import { BolkAuthProvider } from "@bolkauth/react";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <BolkAuthProvider config={{ baseURL: "/api/auth" }}>
          {children}
        </BolkAuthProvider>
      </body>
    </html>
  );
}
```

### 5. Protect Routes via Middleware

Add `middleware.ts` to secure protected paths:

```ts
import { bolkAuthMiddleware } from "@bolkauth/nextjs";
import { auth } from "@/lib/auth";

export default bolkAuthMiddleware(auth, {
  signInUrl: "/sign-in",
  onboardingUrl: "/onboarding",
  publicRoutes: ["/", "/sign-in", "/sign-up", "/api/auth"],
});

export const config = {
  matcher: ["/((?!.*\\..*|_next).*)", "/", "/(api|trpc)(.*)"],
};
```

## 🏛️ Monorepo Architecture

BolkAuth is built as a clean modular monorepo:

| Package | npm Package | Description |
|---|---|---|
| Core Engine | `@bolkauth/core` | Zero-dependency Web Crypto engine handling JWTs, hashing, OAuth, & state machines |
| React Bindings | `@bolkauth/react` | Headless hooks (`useSignIn`, `useSignUp`, `useUser`, `useOAuth`) & cross-tab sync |
| Next.js Helpers | `@bolkauth/nextjs` | Edge middleware, Next.js 14+ Route Handlers, & Server Component helpers |
| Drizzle Adapter | `@bolkauth/adapter-drizzle` | PostgreSQL table definitions and adapter logic for Drizzle ORM |
| Prisma Adapter | `@bolkauth/adapter-prisma` | Schema definitions and type-safe adapter for Prisma ORM |
| CLI Tool | `@bolkauth/cli` | Scaffolding wizard (`bolkauth init`, `add`, `generate`) |
