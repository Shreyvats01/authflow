# Database Adapters

BolkAuth uses a pluggable adapter pattern. You can use official Drizzle or Prisma adapters or write your own custom adapter implementing `BolkAuthAdapter`.

---

## 🌧️ Drizzle ORM Adapter

### Installation

```bash
pnpm add @bolkauth/adapter-drizzle drizzle-orm
```

### Schema Setup (`db/schema.ts`)

Import pre-built table schemas directly from `@bolkauth/adapter-drizzle`:

```ts
export {
  authUsers,
  authAccounts,
  authSessions,
  authVerificationTokens,
  authUserMetadata,
} from "@bolkauth/adapter-drizzle";
```

### Adapter Initialization

```ts
import { createDrizzleAdapter } from "@bolkauth/adapter-drizzle";
import { drizzle } from "drizzle-orm/node-postgres";
import * as schema from "./db/schema";

export const db = drizzle(process.env.DATABASE_URL!, { schema });
export const adapter = createDrizzleAdapter(db);
```

## ◭ Prisma Adapter

### Installation

```bash
pnpm add @bolkauth/adapter-prisma @prisma/client
pnpm add -D prisma
```

### Adapter Initialization

```ts
import { createPrismaAdapter } from "@bolkauth/adapter-prisma";
import { PrismaClient } from "@prisma/client";

const prisma = new PrismaClient();
export const adapter = createPrismaAdapter(prisma);
```
