**BolkAuth** is a modern, developer-first authentication library for TypeScript applications. It gives you a Clerk-like developer experience with headless React hooks and Next.js App Router integrations — while letting you **own your database and infrastructure completely**.

---

## ✨ What You Get

| Feature | Details |
|---|---|
| 🔐 Web Crypto hashing | PBKDF2 (100k iterations) — no native dependencies |
| 🎟️ Stateless JWT sessions | HTTP-only, SameSite=Lax cookies signed with HMAC-SHA256 |
| 🔑 Headless React hooks | `useSignIn`, `useSignUp`, `useUser`, `useOAuth`, `useOnboarding` |
| 🖥️ Next.js App Router | Route Handlers, Edge Middleware, Server Components & Server Actions |
| 🗄️ Pluggable adapters | Official Drizzle ORM & Prisma adapters, or bring your own |
| 🧭 Onboarding FSM | Built-in multi-step onboarding state machine with persistence |
| 📡 Cross-tab sync | Browser `BroadcastChannel` keeps auth state consistent across tabs |
| 🛠️ CLI scaffolding | `bolkauth init` → interactive setup in under 2 minutes |

## ⚡ Quickstart in 5 Steps

### 1. Install Dependencies

```bash
pnpm add @bolkauth/core @bolkauth/nextjs @bolkauth/react @bolkauth/adapter-drizzle
```

### 2. Configure the Auth Engine

Create `lib/auth.ts` to instantiate your BolkAuth engine:

```ts
import { createBolkAuth } from "@bolkauth/core";
import { createDrizzleAdapter } from "@bolkauth/adapter-drizzle";
import { db } from "./db";

export const auth = createBolkAuth({
  adapter: createDrizzleAdapter(db),
  secret: process.env.BOLKAUTH_SECRET!,
  session: {
    maxAge: 60 * 60 * 24 * 30, // 30 days in seconds
    cookieName: "bolkauth.session",
  },
  emailAndPassword: {
    enabled: true,
    minPasswordLength: 8,
  },
  socialProviders: {
    github: {
      clientId: process.env.GITHUB_CLIENT_ID!,
      clientSecret: process.env.GITHUB_CLIENT_SECRET!,
    },
    google: {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    },
  },
  onboarding: {
    enabled: true,
    requiredForAccess: true,
    redirectUrl: "/onboarding",
  },
});
```

### 3. Expose the API Route Handler

Create `app/api/auth/[...bolkauth]/route.ts`:

```ts
import { bolkAuthHandler } from "@bolkauth/nextjs";
import { auth } from "@/lib/auth";

const handlers = bolkAuthHandler(auth);

export const GET  = handlers.GET;
export const POST = handlers.POST;
export const PATCH = handlers.PATCH;
export const DELETE = handlers.DELETE;
```

### 4. Wrap Your App with the React Provider

Update `app/layout.tsx`:

```tsx
import { BolkAuthProvider } from "@bolkauth/react";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <BolkAuthProvider config={{ baseURL: "/api/auth" }}>
          {children}
        </BolkAuthProvider>
      </body>
    </html>
  );
}
```

### 5. Protect Routes via Middleware

Add `middleware.ts` at the project root:

```ts
import { bolkAuthMiddleware } from "@bolkauth/nextjs";
import { auth } from "@/lib/auth";

export default bolkAuthMiddleware(auth, {
  signInUrl: "/sign-in",
  onboardingUrl: "/onboarding",
  publicRoutes: ["/", "/sign-in", "/sign-up", "/api/auth"],
});

export const config = {
  matcher: ["/((?!.*\\..*|_next).*)", "/", "/(api|trpc)(.*)"],
};
```

## 🌍 Environment Variables Reference

| Variable | Required | Description |
|---|---|---|
| `BOLKAUTH_SECRET` | ✅ | Min 32-character secret for HMAC-SHA256 signing. Generate: `openssl rand -base64 32` |
| `DATABASE_URL` | ✅ | PostgreSQL connection string: `postgresql://user:pass@host:5432/db` |
| `GITHUB_CLIENT_ID` | OAuth | GitHub OAuth App client ID |
| `GITHUB_CLIENT_SECRET` | OAuth | GitHub OAuth App client secret |
| `GOOGLE_CLIENT_ID` | OAuth | Google Cloud OAuth 2.0 client ID |
| `GOOGLE_CLIENT_SECRET` | OAuth | Google Cloud OAuth 2.0 client secret |
| `NEXT_PUBLIC_APP_URL` | Deploy | Public URL of your app (used in OAuth callback URLs) |

> **Generating a secure secret:**
> ```bash
> openssl rand -base64 32
> # → outputs something like: xK9mP2qR8sT4vW7yZ1bC3dE5fG6hJ0kL
> ```
