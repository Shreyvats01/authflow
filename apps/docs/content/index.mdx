BolkAuth is a self-hosted authentication toolkit for TypeScript applications. It provides a core auth engine, React hooks, Next.js App Router helpers, middleware, CLI scaffolding, and database adapters while keeping your user data in your own database.

## Start Here

Use these pages in order when adding BolkAuth to a new app:

1. [Installation](/installation) - install the packages for your framework and adapter.
2. [Quick Start](/quick-start) - wire `createBolkAuth`, the route handler, provider, and middleware.
3. [Configuration](/configuration) - set secrets, sessions, email, OAuth, OTP, and onboarding options.
4. [Core Concepts](/core-concepts) - understand the engine, adapter boundary, session model, and request flow.

## Package Map

| Package | Purpose |
|---|---|
| `@bolkauth/core` | Runtime-independent auth engine, sessions, password hashing, OTP, OAuth, and adapter types |
| `@bolkauth/react` | `BolkAuthProvider` and headless hooks for client UI |
| `@bolkauth/nextjs` | App Router route handler, middleware, and server helpers |
| `@bolkauth/adapter-drizzle` | Drizzle ORM adapter with dialect-specific exports |
| `@bolkauth/adapter-prisma` | Prisma adapter and schema examples |
| `@bolkauth/adapter-mongodb` | MongoDB adapter for document storage |
| `@bolkauth/cli` | Scaffolding commands for auth setup and adapter files |
