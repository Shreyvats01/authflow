The `BolkAuthAdapter` interface is the bridge between BolkAuth's core engine and your database. By implementing this interface, you can use BolkAuth with **any** database — MongoDB, MySQL, SQLite, Redis, even a REST API.

---

## 🧩 When You Need a Custom Adapter

- You're using an ORM not covered by the official adapters (e.g., MikroORM, TypeORM, Mongoose)
- You need to integrate BolkAuth into an **existing** User model with different column names
- You're using a non-relational database (MongoDB, DynamoDB, Firebase)
- You want to add custom caching or logging to database calls

---

## 📋 Full BolkAuthAdapter Interface

```ts
import type {
  BolkAuthAdapter,
  CreateUserInput,
  UpdateUserInput,
  CreateSessionInput,
  CreateAccountInput,
  CreateVerificationTokenInput,
  UpdateUserMetadataInput,
  User,
  Session,
  Account,
  VerificationToken,
  UserMetadata,
} from "@bolkauth/core";

export interface BolkAuthAdapter {
  // ─── User operations ────────────────────────────────────────────────────────

  /**
   * Create a new user record.
   * Called during sign-up (email/password) and on first OAuth sign-in.
   * Must return the created user with all fields populated.
   */
  createUser(data: CreateUserInput): Promise<User>;

  /**
   * Find a user by their email address.
   * Returns null if no user with that email exists.
   * Critical path — called on every sign-in attempt.
   */
  getUserByEmail(email: string): Promise<User | null>;

  /**
   * Find a user by their primary key ID.
   * Returns null if the user doesn't exist.
   */
  getUserById(id: string): Promise<User | null>;

  /**
   * Update mutable fields on a user record.
   * Only the provided fields should be updated (partial update).
   * Must return the updated user.
   */
  updateUser(id: string, data: UpdateUserInput): Promise<User>;

  /**
   * Hard-delete a user and all their associated data (cascade).
   * Called when a user deletes their account.
   */
  deleteUser(id: string): Promise<void>;

  // ─── Session operations ──────────────────────────────────────────────────────

  /**
   * Create a new session record in the database.
   * Called after every successful sign-in.
   */
  createSession(data: CreateSessionInput): Promise<Session>;

  /**
   * Find a session by its primary key.
   * Returns null if the session doesn't exist or has been deleted.
   */
  getSessionById(id: string): Promise<Session | null>;

  /**
   * Delete a single session record.
   * Called on sign-out or when a session is explicitly revoked.
   */
  deleteSession(id: string): Promise<void>;

  /**
   * Delete ALL sessions for a given user.
   * Called when a user changes their password or requests "sign out everywhere".
   */
  deleteUserSessions(userId: string): Promise<void>;

  // ─── OAuth account operations ─────────────────────────────────────────────

  /**
   * Link an OAuth provider account to an existing user.
   * Called after a successful OAuth callback when the provider account
   * is not yet linked to any user.
   */
  createAccount(data: CreateAccountInput): Promise<Account>;

  /**
   * Find a linked OAuth account by provider + providerAccountId.
   * Returns null if the account is not linked to any user.
   * Used to look up the associated BolkAuth user during OAuth callback.
   */
  getAccountByProvider(
    provider: string,
    providerAccountId: string
  ): Promise<Account | null>;

  /**
   * Delete a linked OAuth account.
   * Called when a user disconnects a social provider from their account.
   */
  deleteAccount(id: string): Promise<void>;

  // ─── Verification tokens ──────────────────────────────────────────────────

  /**
   * Create a new verification token (email verification or password reset).
   */
  createVerificationToken(data: CreateVerificationTokenInput): Promise<VerificationToken>;

  /**
   * Find a verification token by its value.
   * Returns null if the token doesn't exist or has been consumed.
   */
  getVerificationToken(token: string): Promise<VerificationToken | null>;

  /**
   * Delete a verification token after it has been used.
   * Must be called after successful email verification or password reset.
   */
  deleteVerificationToken(id: string): Promise<void>;

  // ─── User metadata (onboarding) ──────────────────────────────────────────

  /**
   * Create an initial metadata record for a newly registered user.
   * onboardingState should be initialized to "NOT_STARTED".
   */
  createUserMetadata(userId: string): Promise<UserMetadata>;

  /**
   * Fetch the metadata record for a user.
   * Returns null if no metadata record exists (e.g., legacy user).
   */
  getUserMetadata(userId: string): Promise<UserMetadata | null>;

  /**
   * Update the metadata record for a user.
   * onboardingData should be merged with existing data (not replaced).
   */
  updateUserMetadata(userId: string, data: UpdateUserMetadataInput): Promise<UserMetadata>;
}
```

## 📦 Input & Output Types

```ts
interface CreateUserInput {
  id: string;          // pre-generated cuid/uuid
  email: string;
  name?: string | null;
  image?: string | null;
  passwordHash?: string | null;   // "salt:hash" for email/password users
  emailVerified?: Date | null;
}

interface UpdateUserInput {
  name?: string | null;
  image?: string | null;
  emailVerified?: Date | null;
  passwordHash?: string | null;
}

interface CreateSessionInput {
  id: string;
  userId: string;
  expiresAt: Date;
}

interface CreateAccountInput {
  id: string;
  userId: string;
  provider: string;
  providerAccountId: string;
  accessToken?: string | null;
  refreshToken?: string | null;
  expiresAt?: Date | null;
}

interface CreateVerificationTokenInput {
  id: string;
  userId: string;
  token: string;
  type: "email_verify" | "password_reset";
  expiresAt: Date;
}

interface UpdateUserMetadataInput {
  onboardingState?: "NOT_STARTED" | "IN_PROGRESS" | "COMPLETE";
  /** Merged (not replaced) with existing onboardingData */
  onboardingData?: Record<string, unknown>;
  customData?: Record<string, unknown>;
}

// Return types
interface User {
  id: string;
  email: string;
  name: string | null;
  image: string | null;
  passwordHash: string | null;
  emailVerified: Date | null;
  createdAt: Date;
  updatedAt: Date;
  metadata: UserMetadata | null;
}

interface Session {
  id: string;
  userId: string;
  expiresAt: Date;
  createdAt: Date;
}

interface UserMetadata {
  id: string;
  userId: string;
  onboardingState: "NOT_STARTED" | "IN_PROGRESS" | "COMPLETE";
  onboardingData: Record<string, unknown> | null;
  customData: Record<string, unknown> | null;
}
```

## 🏗️ Complete Example: MongoDB Adapter

Here's a full custom adapter implementation for **MongoDB** using the native driver:

```ts
// adapters/mongodb.ts
import { MongoClient, Db, ObjectId } from "mongodb";
import type { BolkAuthAdapter } from "@bolkauth/core";

let client: MongoClient;
let db: Db;

async function getDb(): Promise<Db> {
  if (!client) {
    client = new MongoClient(process.env.MONGODB_URI!);
    await client.connect();
    db = client.db(process.env.MONGODB_DB_NAME ?? "bolkauth");
  }
  return db;
}

export function createMongoAdapter(): BolkAuthAdapter {
  return {
    // ─── Users ─────────────────────────────────────────────────────────────

    async createUser(data) {
      const db = await getDb();
      const now = new Date();
      const doc = {
        _id: data.id,
        email: data.email,
        name: data.name ?? null,
        image: data.image ?? null,
        passwordHash: data.passwordHash ?? null,
        emailVerified: data.emailVerified ?? null,
        createdAt: now,
        updatedAt: now,
      };
      await db.collection("users").insertOne(doc as any);
      return mongoUserToUser(doc);
    },

    async getUserByEmail(email) {
      const db = await getDb();
      const doc = await db.collection("users").findOne({ email });
      if (!doc) return null;

      const meta = await db.collection("userMetadata").findOne({ userId: doc._id });
      return mongoUserToUser(doc, meta);
    },

    async getUserById(id) {
      const db = await getDb();
      const doc = await db.collection("users").findOne({ _id: id });
      if (!doc) return null;

      const meta = await db.collection("userMetadata").findOne({ userId: id });
      return mongoUserToUser(doc, meta);
    },

    async updateUser(id, data) {
      const db = await getDb();
      const update: Record<string, unknown> = { updatedAt: new Date() };
      if (data.name !== undefined) update.name = data.name;
      if (data.image !== undefined) update.image = data.image;
      if (data.emailVerified !== undefined) update.emailVerified = data.emailVerified;
      if (data.passwordHash !== undefined) update.passwordHash = data.passwordHash;

      const { value } = await db.collection("users").findOneAndUpdate(
        { _id: id },
        { $set: update },
        { returnDocument: "after" }
      );
      if (!value) throw new Error(`User ${id} not found`);

      const meta = await db.collection("userMetadata").findOne({ userId: id });
      return mongoUserToUser(value, meta);
    },

    async deleteUser(id) {
      const db = await getDb();
      await Promise.all([
        db.collection("users").deleteOne({ _id: id }),
        db.collection("sessions").deleteMany({ userId: id }),
        db.collection("accounts").deleteMany({ userId: id }),
        db.collection("verificationTokens").deleteMany({ userId: id }),
        db.collection("userMetadata").deleteOne({ userId: id }),
      ]);
    },

    // ─── Sessions ───────────────────────────────────────────────────────────

    async createSession(data) {
      const db = await getDb();
      const doc = {
        _id: data.id,
        userId: data.userId,
        expiresAt: data.expiresAt,
        createdAt: new Date(),
      };
      await db.collection("sessions").insertOne(doc as any);
      return { id: doc._id, ...doc };
    },

    async getSessionById(id) {
      const db = await getDb();
      const doc = await db.collection("sessions").findOne({ _id: id });
      if (!doc) return null;
      return { id: doc._id as string, userId: doc.userId, expiresAt: doc.expiresAt, createdAt: doc.createdAt };
    },

    async deleteSession(id) {
      const db = await getDb();
      await db.collection("sessions").deleteOne({ _id: id });
    },

    async deleteUserSessions(userId) {
      const db = await getDb();
      await db.collection("sessions").deleteMany({ userId });
    },

    // ─── OAuth Accounts ──────────────────────────────────────────────────────

    async createAccount(data) {
      const db = await getDb();
      const doc = { _id: data.id, ...data };
      await db.collection("accounts").insertOne(doc as any);
      return { id: doc._id, ...data };
    },

    async getAccountByProvider(provider, providerAccountId) {
      const db = await getDb();
      const doc = await db.collection("accounts").findOne({ provider, providerAccountId });
      if (!doc) return null;
      return {
        id: doc._id as string,
        userId: doc.userId,
        provider: doc.provider,
        providerAccountId: doc.providerAccountId,
        accessToken: doc.accessToken ?? null,
        refreshToken: doc.refreshToken ?? null,
        expiresAt: doc.expiresAt ?? null,
      };
    },

    async deleteAccount(id) {
      const db = await getDb();
      await db.collection("accounts").deleteOne({ _id: id });
    },

    // ─── Verification Tokens ──────────────────────────────────────────────────

    async createVerificationToken(data) {
      const db = await getDb();
      const doc = { _id: data.id, ...data, createdAt: new Date() };
      await db.collection("verificationTokens").insertOne(doc as any);
      return { id: doc._id, ...data };
    },

    async getVerificationToken(token) {
      const db = await getDb();
      const doc = await db.collection("verificationTokens").findOne({ token });
      if (!doc) return null;
      return {
        id: doc._id as string,
        userId: doc.userId,
        token: doc.token,
        type: doc.type,
        expiresAt: doc.expiresAt,
        createdAt: doc.createdAt,
      };
    },

    async deleteVerificationToken(id) {
      const db = await getDb();
      await db.collection("verificationTokens").deleteOne({ _id: id });
    },

    // ─── User Metadata ────────────────────────────────────────────────────────

    async createUserMetadata(userId) {
      const db = await getDb();
      const id = new ObjectId().toHexString();
      const doc = {
        _id: id,
        userId,
        onboardingState: "NOT_STARTED" as const,
        onboardingData: null,
        customData: null,
        createdAt: new Date(),
        updatedAt: new Date(),
      };
      await db.collection("userMetadata").insertOne(doc as any);
      return { id, ...doc };
    },

    async getUserMetadata(userId) {
      const db = await getDb();
      const doc = await db.collection("userMetadata").findOne({ userId });
      if (!doc) return null;
      return {
        id: doc._id as string,
        userId: doc.userId,
        onboardingState: doc.onboardingState,
        onboardingData: doc.onboardingData ?? null,
        customData: doc.customData ?? null,
      };
    },

    async updateUserMetadata(userId, data) {
      const db = await getDb();
      const existing = await db.collection("userMetadata").findOne({ userId });
      if (!existing) throw new Error(`UserMetadata for ${userId} not found`);

      const update: Record<string, unknown> = { updatedAt: new Date() };
      if (data.onboardingState) update.onboardingState = data.onboardingState;
      if (data.onboardingData) {
        // Merge — don't replace
        update.onboardingData = { ...(existing.onboardingData ?? {}), ...data.onboardingData };
      }
      if (data.customData) {
        update.customData = { ...(existing.customData ?? {}), ...data.customData };
      }

      const { value } = await db.collection("userMetadata").findOneAndUpdate(
        { userId },
        { $set: update },
        { returnDocument: "after" }
      );

      return {
        id: value!._id as string,
        userId: value!.userId,
        onboardingState: value!.onboardingState,
        onboardingData: value!.onboardingData ?? null,
        customData: value!.customData ?? null,
      };
    },
  };
}

// Helper to normalize MongoDB doc → BolkAuth User type
function mongoUserToUser(doc: any, meta?: any | null): any {
  return {
    id: doc._id as string,
    email: doc.email,
    name: doc.name ?? null,
    image: doc.image ?? null,
    passwordHash: doc.passwordHash ?? null,
    emailVerified: doc.emailVerified ?? null,
    createdAt: doc.createdAt,
    updatedAt: doc.updatedAt,
    metadata: meta
      ? {
          id: meta._id as string,
          userId: meta.userId,
          onboardingState: meta.onboardingState,
          onboardingData: meta.onboardingData ?? null,
          customData: meta.customData ?? null,
        }
      : null,
  };
}
```

**Using the MongoDB adapter:**

```ts
// lib/auth.ts
import { createBolkAuth } from "@bolkauth/core";
import { createMongoAdapter } from "@/adapters/mongodb";

export const auth = createBolkAuth({
  adapter: createMongoAdapter(),
  secret: process.env.BOLKAUTH_SECRET!,
});
```

## 🧪 Testing Your Custom Adapter

BolkAuth provides an adapter conformance test suite you can run against your implementation:

```ts
// adapters/__tests__/mongodb.test.ts
import { runAdapterTests } from "@bolkauth/core/testing";
import { createMongoAdapter } from "../mongodb";

// runAdapterTests runs ~30 standardized test cases
// covering all adapter methods and edge cases
runAdapterTests(createMongoAdapter());
```

```bash
pnpm vitest run adapters/__tests__
```

**What the conformance tests cover:**

| Test Group | Cases |
|---|---|
| User CRUD | createUser, getUserByEmail (found/not-found), getUserById, updateUser, deleteUser |
| Session management | createSession, getSessionById, deleteSession, deleteUserSessions |
| OAuth accounts | createAccount, getAccountByProvider, deleteAccount |
| Verification tokens | createVerificationToken, getVerificationToken, deleteVerificationToken |
| User metadata | createUserMetadata, getUserMetadata, updateUserMetadata (merge behavior) |
| Cascade deletes | deleteUser must cascade to sessions, accounts, tokens, metadata |

## ⚡ Performance Tips

- **Index email column**: `getUserByEmail` is on the critical path (called every sign-in). Ensure an index exists.
- **Index session ID**: `getSessionById` is called by middleware on every request. Index it.
- **Index (provider, providerAccountId)**: `getAccountByProvider` is called on every OAuth callback.
- **Merge onboardingData**: Always merge (not replace) in `updateUserMetadata` — the conformance test validates this.
- **Constant-time equality**: Never use `===` to compare tokens in `getVerificationToken`. BolkAuth handles this internally, but be aware.

```ts
// Recommended indexes for MongoDB
await db.collection("users").createIndex({ email: 1 }, { unique: true });
await db.collection("sessions").createIndex({ _id: 1 });
await db.collection("sessions").createIndex({ userId: 1 });
await db.collection("accounts").createIndex(
  { provider: 1, providerAccountId: 1 },
  { unique: true }
);
await db.collection("verificationTokens").createIndex({ token: 1 }, { unique: true });
await db.collection("userMetadata").createIndex({ userId: 1 }, { unique: true });
```
